🚀 브라우저 직접 모드 권장

Gemini API 키를 넣으면 브라우저가 Gemini를 직접 호출합니다.
· Cloudflare의 지역 제한(User location is not supported)을 안 겪습니다
· OpenRouter 하루 50회 대신 Gemini 자체 무료 한도를 씁니다 (훨씬 넉넉)
· 그래서 일수와 상관없이 항상 정밀 모드로 만들어집니다

⚠️ 키는 이 브라우저에만 저장됩니다(localStorage). 개인 기기에서만 쓰시고, 공용 PC에서는 사용하지 마세요. 노출이 의심되면 즉시 재발급하세요.

필수: GEMINI_API_KEY.
OPENROUTER_API_KEY — Cloudflare 서버 IP가 Gemini 지역 제한에 걸릴 때 자동 우회합니다. 한국에서 배포했다면 사실상 필수입니다 (openrouter.ai 무료 발급).
선택: GOOGLE_MAPS_API_KEY(Places API(New) + Routes API 둘 다 Enable) — 좌표·평점·영업시간 검증용. 선택 변수: ENABLE_REDDIT=1, ENABLE_REVIEWS=1
